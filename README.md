# Сервис управления портфолио дизайнера
## Назначение
Проект предназначен для предоставления дизайнерам единого инструмента для управления своими творческими работами. 
Сервис позволяет: 
1. централизованно хранить все проекты и материалы в одном месте;
2. структурировать работы по категориям, тегам, клиентам и датам;
3. формировать публичное портфолио для демонстрации заказчикам и работодателям;
## Целевая аудитория
1. Дизайнеры фрилансеры - специалисты, работающие на себя и нуждающиеся в быстром доступе к своим кейсам
2. Дизайнеры в агентствах- сотрудники, ведущие внутреннюю базу проектов для отчётности и презентаций
3. Начинающие дизайнеры - студенты и джуниоры, формирующие первое портфолио
4. Заказчики и HR -просматривают публичные страницы дизайнеров для найма

## Предметная область
Предметная область — управление творческими работами дизайнера. Ключевые процессы:
1. Добавление работы — загрузка изображений, описания, тегов, категорий, указание клиента и даты.
2. Категоризация и поиск — распределение проектов по папкам/категориям, теги, фильтрация и поиск.
3. Публикация — формирование публичной страницы портфолио с уникальной ссылкой.
4. Аналитика — сбор статистики просмотров, избранного, переходов.
5. Обмен и экспорт — экспорт портфолио в PDF, генерация ссылок для отправки клиентам.

Особенности:
1. мультимедийность (изображения, видео, 3D-превью);
2. версионность работ (черновик / опубликовано / архив);
## Основные сущности
1. User - Пользователь системы (дизайнер):	id, email, password_hash, name, avatar, role
2. Portfolio - Портфолио дизайнера:	id, user_id, title, slug, description, is_public
3. Project - Отдельная работа:	id, portfolio_id, title, description, cover, status, created_at
4. Media - Медиафайлы проекта:	id, project_id, type, url, order
5. Category	- Категория работ:	id, name, slug
6. Tag -Тег для гибкого поиска:	id, name
7. Client-Заказчик проекта:	id, name, contact

Связи:
1. User 1—N Portfolio
2. Portfolio 1—N Project
3. Project N—N Tag
4. Project N—1 Category
5. Project 1—N Media
## Основные функции
Для дизайнера
1. Регистрация и авторизация 
2. Создание и редактирование портфолио.
3. Добавление проектов с загрузкой изображений/видео.
4. Присвоение категорий, тегов, клиентов.
5. Управление статусами работ (черновик, опубликовано, архив).
6. Настройка публичной страницы.
7. Экспорт портфолио в PDF.

Для зрителя (публичная часть)
1. Просмотр публичного портфолио по ссылке.
2. Фильтрация работ по категориям и тегам.
3. Просмотр отдельного кейса.
